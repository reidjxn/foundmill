

## 2026-11-14 — Api inputs: every list has a `.max()` first and every record a key count (GHSA-mrhx-c7xc-m3w5)

- **Where the bound lives.** On the schema the procedure takes, including schemas in `packages/db/src/repos` and `packages/agents` that routers use as their input, so the repos' own `parseInput` and the api agree. Only fields a request can reach were changed; a db schema used only by internal writers keeps its shape.
- **Arrays.** `.max(n)` right after `z.array(...)`, before `.min()` and any refine: zod 4.6.7 then refuses a longer array without reading an element. Lists of enum values take the enum's length (a real client sends each value once). Other limits are named in `INPUT_LIMITS` (packages/config) and set well above what the product sends: 500 department ids (departments are unpaged; the repos' page size), 1,000 linked spec blocks, tasks or sources, 1,000 forecast months (the horizon is 60), 1,000 aliases (a merge adds the merged record's names, written past the schema), 100 tool grants (37 connectors) and 100 tools per grant (16 at most), 500 instruction lines (templates carry 17 at most), 500 register officers (Companies House pages 100 at most).
- **Records.** zod has no cap for a record, and a `.refine` on its size runs after every key, so `boundedRecord(n, record)` counts the keys of a plain object first (as #139 did for the quiz answers) and refuses anything that is not a plain object. Enum-keyed maps (section permissions, notification and email kinds) take the enum's length: a larger object always held an unknown key and was refused before. Free-form JSON objects (a spec block's content, a quiz definition, campaign config, security terms, forecast drivers, simulation params, a connector's connect fields) take 100 top-level keys; their depth stays bounded by the body limit and the service that reads them. The seen marks keep their limit of 50 and their message, now counted before the keys are read.
- **Guarding new inputs.** `input-limits.test.ts` walks every procedure's input and fails on an unbounded array, set or map, or a record outside `boundedRecord`.
