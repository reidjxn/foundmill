# Making images and clips for posts

## When to use this

Use this when a post or update needs a file. Graphics: the Inkscape tools (SVG or PNG) or the GIMP tools (PNG or JPEG). Media: the FFmpeg tools `convert`, `trim`, `extract_audio` and `poster`, which work on files already in the working folder. Each call is one command in the project's sandbox, with no internet.

## How to do it

1. Check the network's size and length limits before you start (for example a square or vertical image, a clip under a minute).
2. Use the project's brand colors and its own footage and pictures. Never use someone else's.
3. Make the file with the smallest number of calls. Name it plainly, such as `launch-post.png` or `clip-30s.mp4`.
4. Report the file name and that it is in the working copy. The founder approves it before any post uses it. You do not publish from the working copy.

## What not to do

- A result marked simulated was not made; say so and do not describe the file.
- Do not trim or convert a clip to hide who said what, or to cut context from someone's words.
- Do not claim a clip or picture is shown anywhere until the founder has approved and used it.
